一、路由核心基础概念

  1. 路由基本原理
    路由过程双向通信，必须有去有回，缺一不可。
    路由器转发数据包的两大关键要素：下一跳、出接口。
    下一跳：下一台路由器的接口 IP 地址，可存在多个下一跳地址。
  2. 路由器核心工作流程
    接收 IP 数据包，解析 IP 头部目的 IP 地址；
    查询本地路由表，按照规则匹配最佳路径；
    将数据包从对应出接口转发至下一跳；
    日常持续维护、更新路由表。
    二、路由表详解
  3. 路由表查看命令
    华为设备查看路由表：
    bash
    运行
    display ip routing-table
  4. 路由表核心字段说明
    表格
    段 含义 作用规则

estination/Mask 目标网络 + 子网掩码 最长匹配原则，精准匹配目标网段
roto 路由协议 / 路由来源 标识路由是直连、静态、OSPF、RIP 等
re（优先级） 路由优先级 数值越低优先级越高，优选同网段路由
ost（开销 / 度量值） 路径开销 同协议同网段，数值越低路径越优，可手动调整
extHop 下一跳地址 转发数据包的下一台路由器接口地址
nterface 出接口 数据包从本路由器哪个接口转发出去
5. 路由表核心规则
路由表仅存放最优路径；
目标网络不在路由表中，数据包直接丢弃；
子网掩码：划分网段 + 路由匹配的核心依据，遵循最长匹配原则。
6. 最长匹配原则
路由器查找路由表流程：
目的 IP 与路由表掩码做与运算；
匹配路由表目标网段；
优先选择掩码最长的路由作为转发路径。
三、等价路由、负载均衡与路由备份
7. 等价路由 ECMP
全称：Equal Cost Multi-Path 等价多路径
同一路由协议、同一目标网络，优先级、开销值完全相同；
多条路由同时写入路由表，流量自动负载分担；
分担算法：轮询、哈希、比例分配，非平均分配；
作用：叠加带宽、均衡链路压力、链路冗余。
8. 负载均衡 VS 路由备份（主备路由）
表格
性 负载均衡（ECMP） 路由备份（浮动静态 / 主备）
径使用 多条链路同时工作 仅主链路工作，备用链路休眠
由优先级 优先级完全一致 主路由优先级更高（数值更小）
宽利用 多链路带宽叠加 仅主链路带宽生效
障切换 单链路故障，剩余链路分担流量 主链路失效，备用链路自动接管
置目的 提升吞吐量、均衡负载 网络冗余、高可用故障备份
用场景 骨干网、数据中心、多链路聚合 企业双出口、末梢网络备份
配置示例
负载均衡（两条静态路由优先级、开销一致）
bash

ip route-static 10.0.0.0 255.255.255.0 1.1.1.1
ip route-static 10.0.0.0 255.255.255.0 2.2.2.2
路由备份（浮动静态路由，修改优先级）

备路由 调高优先级数值，作为备份

四、路由的三大来源

  1. 直连路由
    来源：路由器接口配置 IP 且接口 UP，自动生成；
    优先级：Pre=0，优先级最高，不可手动修改。
  2. 静态路由
    来源：管理员手工手动配置；
    特点：拓扑变更需手动修改，适合小型固定网络；
    默认优先级：Pre=60。
    静态路由配置命令
    bash
    运行
    ip route-static 目标网络 子网掩码 下一跳地址/出接口
    配置注意：
    以太网接口：必须指定下一跳；
    串口接口：可填下一跳或出接口；
    通信双向，务必配置回程路由；
    工程中优先使用下一跳地址配置。
  3. 动态路由
    来源：路由器通过路由协议自动邻居学习、同步路由；
    特点：拓扑变化自动收敛，无需人工干预，适合中大型网络。
    五、缺省路由（默认路由）
  4. 概念
    特殊路由：0.0.0.0/0，所有路由表无匹配网段的数据包，全部按照缺省路由转发。
  5. 应用场景
    家庭上网、企业出口、末梢网络，充当网关角色。
  6. 配置命令
    bash
    运行
    ip route-static 0.0.0.0 0.0.0.0 下一跳地址
  7. 补充
    可通过静态路由手工配置，也可通过 OSPF 等动态协议发布：
    bash
    运行

OSPF发布缺省路由

default-route-advertise
六、Loopback 回环接口

  1. 特点
    虚拟逻辑接口，创建后默认永远 UP，不受物理链路影响；
    稳定性极强，常用于设备管理、协议搭建。
  2. 配置命令
    bash
    运行

创建回环口

interface loopback 0

配置IP地址

ip address 1.1.1.1 255.255.255.0
3. 核心作用
模拟直连网段，用于网络测试；
作为 OSPF、BGP、MPLS 等协议的 Router-id / 源地址；
SNMP 告警消息源地址；
代替物理接口做设备远程管理。
七、静态路由 & 动态路由 区别
表格
比项 静态路由 动态路由
置方式 管理员手工逐条配置 路由协议自动邻居学习
扑变更 网络变化需手动修改路由 拓扑变化自动收敛更新
用场景 小型网络、拓扑固定 中大型网络、拓扑易变更
源开销 占用 CPU、带宽极低 协议报文占用一定带宽和设备性能
八、动态路由协议分类
4. 按作用范围划分
IGP 内部网关协议：同一 AS 自治系统内部使用
协议：RIP、OSPF、IS-IS
EGP 外部网关协议：不同 AS 自治系统之间使用
协议：BGP（全球互联网骨干路由核心协议）
自治系统 AS：统一管理下的网络，如电信、移动、企业内网。
5. 按算法类型划分
距离矢量协议
代表：RIP、EIGRP（思科私有）
特点：只看跳数 / 距离 + 转发方向，配置简单、扩展性差；RIP 仅以跳数选路，不考虑链路带宽。
链路状态协议
代表：OSPF、IS-IS
特点：泛洪 LSA 链路状态通告，全网同步拓扑数据库，自己计算最优路径；仅链路变化时更新报文，节省带宽。
6. 按是否携带子网掩码划分
有类路由 Classful：不携带掩码，如 RIPv1、IGRP；依赖 IP 默认 A/B/C 类网段，易子网路由错误。
无类路由 Classless：携带掩码，如 RIPv2、OSPF、IS-IS、BGP；支持子网划分，现代网络全部使用无类路由。
九、路由协议基础规则
路由协议运行在接口上，接口未启用则无法学习路由；
同协议可直接互相学习路由，不同协议不能直接共享；
跨协议路由交换需要路由引入 import-route。
路由引入示例（RIP 引入 OSPF 路由）
bash
运行

方式1：手动宣告网段

network 192.168.200.0

方式2：协议引入

import-route ospf 1
十、路由收敛 & 协议性能指标

  1. 路由收敛
    所有路由器路由表同步完整网络路由信息，网络达到稳定转发状态；收敛完成前网络无法正常全网通信。
    RIP 收敛速度最慢，OSPF/IS-IS 收敛更快。
  2. 动态路由协议衡量指标
    正确性：无路由自环、可选出最优路径；
    快收敛：拓扑变更后快速更新路由；
    低开销：占用设备 CPU、内存、网络带宽小；
    安全性：具备防攻击、协议认证机制；
    普适性：适配各类网络拓扑与大中小型网络规模。
