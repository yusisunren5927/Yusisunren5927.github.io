linux常用命令

发表于 2026-05-25

一、文件与目录操作

命令 作用 常用示例
ls 列出目录内容 ls -l 详细列表，ls -a 显示隐藏文件
cd 切换目录 cd /home，cd .. 返回上级，cd ~ 回家目录
pwd 显示当前所在路径 pwd
mkdir 创建目录 mkdir mydir，mkdir -p a/b/c 创建多级目录
rmdir 删除空目录 rmdir emptydir
rm 删除文件或目录 rm file.txt，rm -r dir 递归删除，rm -f 强制
cp 复制文件或目录 cp a.txt b.txt，cp -r dir1 dir2
mv 移动或重命名 mv old.txt new.txt，mv file /dest/
touch 创建空文件或更新时间戳 touch newfile.txt
cat 查看完整文件内容 cat file.txt
more / less 分页查看文件 less bigfile.log（可上下翻页）
head 查看文件开头（默认10行） head -20 file.txt
tail 查看文件末尾 tail -f log.txt 实时跟踪
find 按条件查找文件 find / -name "*.conf"
grep 搜索文本内容 grep "error" log.txt，grep -r "hello" .

二、权限管理

命令 作用 常用示例
chmod 修改文件权限 chmod 755 script.sh，chmod u+x file
chown 修改文件所有者 chown user:group file.txt
chgrp 修改文件所属组 chgrp staff file.txt
umask 设置默认权限掩码 umask 022

三、进程管理

命令 作用 常用示例
ps 查看进程快照 ps aux，ps -ef
top / htop 动态查看进程资源占用 直接输入 top，按 q 退出
kill 终止进程 kill 1234，kill -9 1234 强制结束
pkill 按名称杀进程 pkill firefox
jobs 查看后台任务 jobs -l
bg / fg 将任务放到后台/前台运行 fg %1
nohup 让命令在后台脱离终端运行 nohup ./server &

四、网络操作

命令 作用 常用示例
ping 测试网络连通性 ping baidu.com
ifconfig / ip 查看网络接口配置 ifconfig 或 ip addr
netstat 查看网络连接、路由表等 netstat -an，netstat -tulnp
ss 更快的 socket 统计（替代 netstat） ss -tuln
curl 发送 HTTP 请求 curl https://api.example.com
wget 下载文件 wget https://example.com/file.zip
ssh 远程登录 ssh user@hostname
scp 远程复制文件 scp local.txt user@remote:/path/

五、压缩与打包

命令 作用 常用示例
tar 打包/解包（常结合压缩） tar -czvf archive.tar.gz dir/（压缩）
tar -xzvf archive.tar.gz（解压）
gzip / gunzip 压缩/解压 .gz 文件 gzip file.txt，gunzip file.gz
zip / unzip 处理 .zip 文件 zip -r my.zip dir/，unzip my.zip

六、系统信息与资源查看

命令 作用 常用示例
uname -a 查看内核/系统版本 uname -r 只查内核
df -h 查看磁盘分区使用情况 df -h（人类可读）
du -sh 查看目录或文件大小 du -sh /home
free -h 查看内存使用 free -h
uptime 查看系统运行时间、负载 uptime
whoami 当前用户名 whoami
hostname 查看/设置主机名 hostname
date 查看/设置系统时间 date
man 查看命令手册 man ls

七、文本编辑（终端内）

命令 作用
vim / vi 功能强大的编辑器，需要学习基本操作
nano 简单易上手的编辑器，适合新手
echo 输出文本（常用来写文件）

八、快捷键与特殊符号

快捷键/符号 作用
Ctrl + C 终止当前命令
Ctrl + Z 暂停当前命令（可用 fg 恢复）
Ctrl + D 退出终端或发送 EOF
↑ / ↓ 浏览历史命令
Tab 自动补全命令或路径
history 显示历史命令记录
!! 执行上一条命令
> 重定向输出（覆盖）
>> 重定向输出（追加）
|（管道符） 将前一个命令的输出作为后一个命令的输入

提示：绝大多数命令都可以使用 --help 选项查看简要帮助，例如 ls --help。
想要深入掌握，建议多用 man 命令查阅官方手册。
