一、DHCP 基础概述

  1. 全称：Dynamic Host Configure Protocol 动态主机配置协议
  2. 由 BOOTP 协议发展而来，应用层协议，基于 UDP 封装
  3. 端口号：
    • 客户端：68
    • 服务器：67
  4. 作用：自动给终端分配 IP、子网掩码、网关、DNS 等参数
  5. 分配的IP带有租期，不是永久使用
  6. DHCP 客户端请求默认以广播发送

二、DHCP 网络组成角色

  1. DHCP Client 客户端：电脑、手机等需要自动获取IP的终端
  2. DHCP Server 服务器：负责分配IP地址池、下发网络参数
  3. DHCP Relay 中继
    • 路由器、三层交换机充当
    • 作用：跨广播域转发DHCP广播报文，让不同网段也能共用一台DHCP服务器
  4. 客户端与服务器不在同一广播域，必须配置DHCP中继

三、DHCP 六种报文类型

报文 作用
DHCP Discover 客户端广播寻找DHCP服务器
DHCP Offer 服务器回应，携带可用IP和网络参数
DHCP Request 客户端广播确认选用哪个服务器的IP、申请租约/续期
DHCP ACK 服务器确认分配IP、下发完整参数
DHCP NAK 服务器拒绝分配IP
DHCP Release 客户端主动释放IP地址

四、DHCP 经典工作流程（四步握手）

Discover（广播）→ Offer → Request（广播）→ ACK

  • 第1、3步固定广播
  • 第2、4步可单播也可广播（教材两种说法都成立）
  • 网络中多台DHCP服务器时，谁先回复Offer，客户端就选用谁的IP

五、DHCP 租期机制

1. 租期更新（50%）

租约用到 50% 时，客户端单播向服务器发起续期请求，成功则刷新租期。

2. 重绑定（87.5%）

50%续期无响应，到 87.5% 时改为广播重新申请IP；
收到ACK继续用，收到NAK立即停用IP。

3. 地址释放

  • 租期到期无续约，自动停用IP
  • 也可手动发 DHCP Release 主动释放

4. APIPA 自动私有地址

Windows 客户端获取不到DHCP地址时，自动给自己分配：
169.254.0.0/16 网段地址，只能同网段临时互通。

5. 租期设置建议

  • 短租期：机场、商场、酒店等流动用户多的场景，增加设备负担
  • 长租期：家庭、企业固定终端，减轻网络负担

六、DHCP 两种地址池

  1. 接口地址池
    • 绑定在三层接口
    • 直接以接口IP作为用户网关
    • 优先级高于全局地址池
  2. 全局地址池
    • 全局创建IP地址池，可被多个接口调用
    • 需手动配置网段、网关、DNS、租期等

九、重点易错知识点

  1. DHCP 基于 UDP 67/68，应用层协议
  2. 跨网段必须 DHCP中继
  3. 接口地址池优先级 > 全局地址池
  4. 地址池 network 网段是必配，网关、DNS为选配
  5. 可配置排除IP，预留给服务器、网关等固定设备
  6. 静态IP+MAC绑定，地址永久不分配给其他人
  7. 获取不到DHCP自动出 169.254.x.x 私有地址
  8. 四步握手：1、3广播；2、4可单播可广播，两种教材说法都对
  9. 多DHCP服务器环境，先到先得，客户端选用最先收到的Offer
